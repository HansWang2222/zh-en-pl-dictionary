# 完整成品示例

下面两条是照模板写出的成品，可直接对照格式。表内形式取自 Wikisłownik，例句为地道英–波对译。

---

## 示例一：名词 `kot`

# kot  [kɔt] · 名词，阳性动物性（m-zw.） · 猫

## 释义

1. 猫，家猫（*Felis catus*）— **cat** — *kot domowy*
2. 公猫 — **tomcat** — *kocur*

## 百科

家猫约一万年前由近东的非洲野猫驯化而来，如今是最常见的家养动物之一。

## 变格

| 格 | 单数 | 复数 |
| --- | --- | --- |
| M. mianownik 主格 | kot | koty |
| D. dopełniacz 属格 | kota | kotów |
| C. celownik 与格 | kotu | kotom |
| B. biernik 宾格 | kota | koty |
| N. narzędnik 工具格 | kotem | kotami |
| Ms. miejscownik 前置格 | kocie | kotach |
| W. wołacz 呼格 | kocie | koty |

注：复数呼格与主格同形；`kotowie` 只用于口语戏称“新兵/新生”，不列入主表。

## 例句（EN–PL）

1. **EN:** The cat is sleeping.
   **PL:** **Kot** śpi.

2. **EN:** I have a cat and a dog.
   **PL:** Mam **kota** i psa.

3. **EN:** The cat is chasing the mouse.
   **PL:** **Kot** goni za myszą.

## 示例二：动词 `pisać`

# pisać  [ˈpʲisat͡ɕ] · 动词，未完成体（impf.），及物 · 写

体：pisać (impf.) ↔ napisać (pf.)

## 释义

1. 写，书写 — **write** — *pisać*
2. 写作，撰写（文章、书、报告）— **write, compose** — *pisać*
3. 拼写 — **spell** — *pisać się*（`Jak się to pisze?` 这怎么拼？）

## 变位

### 现在时

| 人称 | 形式 |
| --- | --- |
| ja | piszę |
| ty | piszesz |
| on / ona / ono | pisze |
| my | piszemy |
| wy | piszecie |
| oni / one | piszą |

### 将来时

| 人称 | 形式 |
| --- | --- |
| ja | będę pisać / będę pisał(a) |
| ty | będziesz pisać / będziesz pisał(a) |
| on / ona / ono | będzie pisać / będzie pisał(a) |
| my | będziemy pisać / będziemy pisali(-ły) |
| wy | będziecie pisać / będziecie pisali(-ły) |
| oni / one | będą pisać / będą pisali(-ły) |

### 过去时

| 人称 | 阳性 | 阴性 | 中性 |
| --- | --- | --- | --- |
| ja | pisałem | pisałam | pisałom |
| ty | pisałeś | pisałaś | pisałoś |
| on / ona / ono | pisał | pisała | pisało |
| my | pisaliśmy | pisałyśmy | — |
| wy | pisaliście | pisałyście | — |
| oni / one | pisali | pisały | — |

### 其他形式

- 命令式：pisz / piszmy / piszcie；niech pisze / niech piszą
- 条件式：pisałbym / pisałabym；pisałbyś / pisałabyś；pisalibyśmy / pisałybyśmy
- 主动形容词分词：piszący / pisząca / piszące
- 被动形容词分词：pisany / pisana / pisane
- 副动词：pisząc
- 动名词：pisanie
- 无人称过去时：pisano

注：完成体 `napisać` 没有现在时，`napiszę` 等形式表示将来，不要与上表混用。

## 例句（EN–PL）

1. **EN:** She writes a letter every day.
   **PL:** Ona codziennie **pisze** list.

2. **EN:** I was writing all evening.
   **PL:** **Pisałem** przez cały wieczór.

3. **EN:** Write legibly!
   **PL:** **Pisz** wyraźnie!

## 常见错误

- 把中文译文塞进例句区（用户明确不要）。
- 用英语语序硬造波兰语句子，或把 `się` 漏掉。
- 给完成体配“现在时”表，或把完成体现在时标成现在。
- 名词表只给单数，或漏掉呼格。
- 把 Glosbe 的机器直译（如 `kot` → “dust bunny”）当义项。
- 变形表凭规则硬推而不核对来源，尤其是有辅音交替的格。
